# Broader data search for CollisionGuard

Research date: 15 November 2026 UTC. No newly inspected source has yet established a usable primary-study pair. The strongest broad-coverage lead is AgentLogs: two development session-to-task associations are verified, but their common starting tree and session-specific outputs are not. SWE-rebench/OpenHands is the next lead for controlled, independently executed tasks. CooperBench's no-communication release adds repository coverage, but the checked pair already shared plans. These are not grounds to choose final test repositories.

The existing [ParallACT inventory](parallact-expansion-readiness.md) has 57 remaining candidate paths in nine repositories after its stated exclusions. Only eight paths, in one repository, are outside all previously selected cases. Paths are not verified independent families or usable labels. Its 12 released development cases include Teleport, Proton Mail webclients, NodeBB, Flipt, Navidrome, Open Library, Vuls and Ansible. Prior audits also inspected Element Web and CooperBench Outlines. New source totals below are author claims or small metadata checks, not estimates of usable pairs. No new merge label was examined or generated.

## Terms, construction and scope

AgentLogs declares CC BY 4.0 for its dataset, while explicitly reserving GitHub, API, product and third-party rights; it does not grant blanket rights to prompt text or code. Its collection favors public repositories with a star threshold and observed cloud-agent sessions. [Terms](https://github.com/risenlab/agentlogs/blob/0af19d213339e26d0f3e447be11cd2d73d5ea505/DATA_LICENSE), [README](https://github.com/risenlab/agentlogs/blob/0af19d213339e26d0f3e447be11cd2d73d5ea505/README.md).

The Nebius task and trajectory cards declare CC BY 4.0; the task card also requires respect for each underlying repository license. The trace card does not settle every prompt, model-output or source-code right. RootSE's card declares MIT, without resolving all upstream content rights. CooperBench's trajectory card declares MIT; original tasks, source repositories and outputs still need their own scope checked. CHAIN's Zenodo metadata declares CC BY 4.0 for the deposit; its code repository has a GPL-3.0 license. Embedded session and repository rights remain a separate question. GATC's card declares Apache-2.0 but also requires acceptance of access conditions. TraceLab's terms were not independently audited because the described sanitized data lack required fields. [Nebius tasks](https://huggingface.co/datasets/nebius/SWE-rebench/blob/89cdfbab4ab1bd8f5a658bb212d1b63624f4f881/README.md), [Nebius traces](https://huggingface.co/datasets/nebius/SWE-rebench-openhands-trajectories/blob/35455389ab51bf5e2306bfd436ef72d0f98bf882/README.md), [RootSE](https://huggingface.co/datasets/dengdan1999/RootSE/blob/c3e54cf25f99eddd85d8c9cbe3f41528e5e7f957/README.md), [CooperBench card](https://huggingface.co/datasets/CooperBench/trajectories/blob/906bc2f62325eb6f8ccb4cf221e63df051cb3c99/README.md), [CHAIN metadata](https://zenodo.org/api/records/24104601), [CHAIN code license](https://github.com/dessertlab/CHAIN-dataset/blob/4135a8112855ca5b465038d6632da0dc398d3596/LICENSE), [GATC](https://huggingface.co/datasets/GOAT-AI/gatcv6).

## Proposed bounded next pilot

Freeze a metadata-only candidate frame before reading outcomes. First check a small, predeclared set of AgentLogs task/session pairs across at least five repositories outside all existing development repositories, then check SWE-rebench pairs only when two distinct task IDs share an exact recorded base. Preserve all attempted candidates and exclusions. For each, require the original instructions and allowed repository context before either start, complete session history sufficient to exclude partner plans or communication, proof of the actual common starting tree, distinct task/run association, and two separate complete agent outputs. Record access failures as unavailable. Verify output ownership and underlying terms before a later full-tree Git replay; do not equate PR head, gold patch, integrated output, file overlap or functional test success with the target. Count distinct repositories and task families that pass each gate. The present search established zero new usable replay labels.

If those gates yield too few independent repositories, prepare a small controlled-generation pilot on new repositories. Freeze two genuinely distinct task instructions and the same exact clean commit before dispatch, run each agent in an isolated workspace without partner information, capture prompts, environment, actual base and separate outputs, and retain failures. Freeze candidate and held-out repositories before any tuning. This is a recommendation only; no agents or paid model calls were launched. Keep repository-separated folds and related tasks together. Use the agreed prevalence, TF-IDF, logistic and direct-boosting comparisons, followed by out-of-fold predicted footprints; average precision remains primary. No final test repositories are selected here.
