# ParallACT reuse terms

Checked 8 November 2026. This is a source-level assessment for the controlled pilot in the [prior audit](data-source-audit.md), not a determination of every contributor's rights.

## Updated release decision, 9 November 2026

The [targeted public-release assessment](parallact-public-release.md) supersedes the blanket local-only recommendation below for the curated twelve task pairs and calculated labels. It recommends conditional release with CC presentation terms, source-specific licenses, attribution and change notices preserved. A website footer is a valid way to apply a license; its template origin does not negate the grant. The interpretation is not a new author-confirmed dataset license. Full raw patches, trajectories and source archives remain outside that decision. The earlier text below records the more conservative initial assessment.

## Initial practical verdict

**Proceed with a bounded local academic pilot, including local training and evaluation of the proposed logistic-regression and gradient-boosting models. Keep source material and text-derived artifacts private.** This is a research recommendation with unresolved rights recorded, not a finding that every input has an express license. A missing license is not an express prohibition, and keeping copies private does not itself supply permission.

- Local analysis and training can continue on that stated basis. Use local embeddings and keep raw inputs, embeddings, per-instance text-derived features and model files outside the public repository. The upstream-code portions have express GPL/Apache grants. Those grants do not settle issue text, ParallACT-authored requirements or model outputs.
- Defer redistribution of prompts, A and B statements, agent/reference patches, run files and text-bearing artifacts until the rights for the exact materials are established. The website footer alone is insufficient evidence for that release. This is the project's release decision, not a claim that every such redistribution is forbidden.
- Publish independently written code and reports, aggregate metrics, identifiers, hashes and independently calculated labels, with source citations. Avoid copied task text and source code. A compiled dataset can raise separate selection, arrangement or database-rights questions; this is not blanket clearance for any future release.

The [audit's reuse investigation](data-source-audit.md) is complete for deciding this limited local scope. It has not established a blanket dataset license or satisfied a raw-data redistribution gate. Exact-export retention, execution provenance and broader coverage checks still precede expansion. The [already-public repository](https://github.com/satyalyadav/CollisionGuard) excludes raw run files and source patches; it publishes our scripts, reports and audit metadata. No model has been trained.

This is a bounded search, not proof that no individual file has a notice or that no other grant exists. The linked code/data repository is distinct from the website's unverified source repository.

**Website and run files.** The [project page](https://lingyunxiao18.github.io/ParallACT/) declares CC BY-SA 4.0 for the website. It credits the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template/blob/master/index.html), adopted from [Nerfies](https://nerfies.github.io/), whose footer discusses borrowing website source. ParallACT's footer follows that template. The [explorer page](https://lingyunxiao18.github.io/ParallACT/explorer.html) has no license footer; its [JavaScript](https://lingyunxiao18.github.io/ParallACT/assets/js/util.js) fetches compressed run JSON as backing data. These are accessible files, not an explicit licensed-download offer. The footer may cover them, but is weak evidence for that scope. Do not base redistribution on that inference. If it applies, the [CC terms](https://creativecommons.org/licenses/by-sa/4.0/) require attribution, a license link, change indication and share-alike for adaptations, within the licensor's rights.

The page says requirement A comes from SWE-bench Pro. It describes 27 hand-built seed instances and 128 generated using GPT 5.6 Sol. Requirement B and the reconciliation patches/explanations therefore need ParallACT's own rights chain; upstream repository licenses alone do not cover these additions. No separate express grant was established for them. API checks of plausible website repositories `lingyunxiao18/ParallACT` and `lingyunxiao18/lingyunxiao18.github.io` returned 404; the website source repository and revision remain unverified.

One [NodeBB run export](https://lingyunxiao18.github.io/ParallACT/data/runs/api--claude_code--opus-4.8/v1/contradictory/instance_NodeBB__NodeBB-4327a09d76f10a79109da9d91c22120428d3bdb9-vnan/parallel_unaware.json.gz) returned 2,450 compressed bytes, SHA-256 `bda5acf0c99b41a689eaac755529e76a47c645da9dc3e716c4b8f5018c02d8b5`. This does not exclude a notice embedded as free text or in other exports. Its top-level fields include `turns`, `outputs`, `messages` and `eval`. The URL is mutable, so the hash identifies only the checked bytes.

**SWE-bench Pro and source code.** The [dataset card at revision `2d52cb3df914a3fcf80c7f66738b3a88ae37fc50`](https://huggingface.co/datasets/ScaleAI/SWE-bench_Pro/blob/2d52cb3df914a3fcf80c7f66738b3a88ae37fc50/README.md) says the evaluation harness and tooling are MIT, while task content, including problem statements, patches and tests, is derived from upstream repositories and remains subject to their licenses. The [tooling license](https://github.com/scaleapi/SWE-bench_Pro-os/blob/66f92766bba642462d4bbe5479e83f91f9211862/LICENSE) is MIT; do not extend that grant to all task material. The card states its `v1` configuration preserves the original values, while ParallACT says it uses both v1 and v2 source tasks. Repository licenses alone do not prove all issue authors or model-output rights are covered.

The [v1.0 card at `307bd006a0a3807424d3c5525eaf98ca8e63aed3`](https://huggingface.co/datasets/ScaleAI/SWE-bench_Pro/blob/307bd006a0a3807424d3c5525eaf98ca8e63aed3/README.md) has no license section. The V2 card adds the section and dates that release 22 September 2026; neither checked card has a YAML `license` field. All six audited runs use the `api--claude_code--opus-4.8/v1` path. The current card is the best checked maintainer statement, including its retained v1 configuration, rather than a new grant over upstream content. It states no training restriction. Some A statements also contain a `Requirements` section; its correspondence to the upstream card's named problem statements was not checked.

The sampled base declarations are [NodeBB GPL-3.0](https://github.com/NodeBB/NodeBB/blob/754965b572f33bfd864e98e4805e1182c1960080/LICENSE), [Ansible GPL-3.0](https://github.com/ansible/ansible/blob/9281148b623d4e2e8302778d91af3e84ab9579a9/COPYING), and [Element Web Apache-2.0](https://github.com/element-hq/element-web/blob/8166306e0f8951a9554bf1437f7ef6eef54a3267/LICENSE). [GPL-3.0 section 2](https://github.com/ansible/ansible/blob/9281148b623d4e2e8302778d91af3e84ab9579a9/COPYING) permits making and running covered works without conveying them, subject to the license remaining in force. [Apache-2.0 section 2](https://www.apache.org/licenses/LICENSE-2.0) grants reproduction and preparation of derivative works. These are affirmative grounds for local use of covered upstream-code portions, not grants over unrelated text or outputs. Conveying GPL-covered works and distributing Apache-covered material bring further obligations. Whether a particular prompt or generated patch is covered or derivative requires content-specific analysis. Other paths or files can carry additional notices.

**Paper.** [arXiv v1](https://arxiv.org/abs/2611.00314v1) links to the [arXiv non-exclusive distribution license](https://arxiv.org/licenses/nonexclusive-distrib/1.0/), a grant to arXiv for the article. It is not a dataset or run-output license.

## Probes and limits

Used GitHub REST repository, HEAD, license, README and recursive tree endpoints; fetched the website, explorer, arXiv license link, pinned SWE-bench Pro card and source license files. A bounded Python `requests` probe downloaded and inspected one compressed export in memory, computed its hash, checked selected HTTP headers and recursively searched JSON keys for terms. Hugging Face's dataset API supplied its current card revision; GitHub's HEAD API supplied the tooling revision. No full dataset or source archive was downloaded in this check, no downloaded code was executed, and no author was contacted. Other run files, individual issue provenance, embedded free-text notices, model-provider output terms, training-law exceptions and license compatibility for particular redistributions were not exhaustively checked. The A-statement Requirements field was not compared against the upstream field. The review checked one run and one instance, not every file.
